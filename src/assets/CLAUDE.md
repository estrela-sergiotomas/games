# assets/ - Assets do Jogo

Arquivos estaticos (audio, imagens).

- `music.ts` - Gera musica 80s synthwave programaticamente via Web Audio API. Nenhum arquivo de audio externo e necessario.

## Nota
A maioria dos sprites (aviao, explosao, particulas) sao gerados programaticamente em PlaneSprite.ts via Phaser Graphics, nao sao arquivos de imagem.
